# HCOS — HDOS CP/M Operating System

A single operating system for the Heathkit H8 and H89 that runs both
**HDOS** (`.ABS`) and **CP/M 2.2** (`.COM`) programs, written in pure 8080
assembly.

Status: design phase. No code yet.
